## English TL;DR

A curated set of **C/C++ practice topics** — 20 folders walking from the first `hello` program through pointers, classes, copy constructors, operator overloading and lambdas, up to a capstone student-management system and a custom math DLL.

- 📚 One folder per topic, indexed in the table below
- 🧪 Each topic is a standalone compilable sample, not just notes
- 🇨🇳 Docs are in Chinese.

| 目录 | 内容 |
| --- | --- |
| FirstC++ | 入门第一个程序 |
| Basic_Data_Type | 基本数据类型 |
| If-else | 条件语句 |
| Switch | 多分支语句 |
| For | for 循环 |
| While_Do-while | while / do-while 循环 |
| Function | 函数定义与调用 |
| Return | 返回值 |
| ParameterPassing | 参数传递方式 |
| Array | 数组 |
| Ptr | 指针 |
| Class | 类与对象 |
| Copyfunction | 拷贝构造函数 |
| Fengzhuang | 封装 |
| Operator | 运算符重载 |
| Lambda | Lambda 表达式 |
| Stack_heap | 栈与堆 |
| Student_management_system | 学生管理系统综合练习 |

| 简易待办事项列表 | 待办事项小项目 |
